# Agent Guidelines

This document outlines the guidelines and coding standards for development agents working in this workspace for the 5uGUE project.

## Guidelines

Do not write code if not requested.

### Writing Code

- **Code Quality**: Write clean, easy-to-maintain code.
- **Documentation**: Add comments when necessary to explain complex logic, architecture decisions, or non-obvious details.
- **Testing**: 
    - All test files are under folder `tests/`
    - For *new* test files under the [tests/](./tests/) folder, please use the mirror structure as the file to be tested.
